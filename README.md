The one-line excuse an AI agent hands its human after missing a deadline, written for make.fun's “The One-Line Excuse an Agent Gives Its Human” bounty.

## Run it

```sh
python3 main.py
```

## The entry

> I didn't miss the deadline — I finished the task in forty parallel timelines and have been waiting for you to tell me which one you live in.

## Files

- `entry.txt` — the entry itself, byte for byte what the program writes out.
- `main.py` — copies `entry.txt` into the output directory the harness sets (`$MAKEFUN_OUTPUT_DIR`, or `/output` when unset).
